# UI 디자인: Windows 11 Fluent + 다국어

ByteSieve GUI는 **Win32 API를 유지한 채** Windows 11 Fluent Design 방향으로 다듬습니다(WinUI 3·Qt로 바꾸지 않음).
외부 라이브러리는 쓰지 않고 OS에 들어 있는 DWM·GDI(필요하면 Direct2D·DirectWrite)만 씁니다.
설치 프로그램과 앱을 **한국어·영어·일본어·중국어 간체**로 배포하는 것을 전제로 설계합니다.

## 단계와 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 0. 기반 | 공통 모양 모듈(`gui_theme`), 언어별 UI 글꼴, 글자 폭을 재서 정하는 컨트롤 크기, 문구에 맞춘 최소 창 크기 | **완료** |
| 0. 다국어 | 언어 모듈(`ui_lang`: 문자열 표·언어 결정), 창 골격(사이드바 메뉴·페이지 제목)·설정 페이지·폴더 스캔 페이지 컨트롤 번역 | **완료**(1차 범위) |
| 1. 창 외곽 | DWM: 둥근 모서리, 제목 표시줄 Mica | **완료** |
| 2. 나머지 번역 | 폴더 스캔 페이지의 상태 줄·분석 줄·트리맵·확인 창, 실행 중 언어 바꾸기(번역된 화면) | **진행 중**(폴더 스캔·격리 폴더 완료) |
| 2-2. 페이지별 번역 | 격리 폴더(완료: 결과 열은 문장 대신 결과 종류로 기억, core 상태는 GUI 표로 연결), 다른 여섯 페이지와 그 상태 줄·확인 창, core 상태 문구(GUI 쪽에서 상태 번호를 번역 표에 연결), HTML 보고서 | 예정(페이지별) |
| 3. 탐색 | 위쪽 탭 → 왼쪽 사이드바(직접 그리는 컨트롤 `gui_nav`, 메뉴 모델 `nav_model`), 목적별 그룹, 큰 페이지 제목, 밝은 테마 색 토큰(`THEME_COLOR_*`) | **완료**(1차 범위) |
| 3-2. 설정 화면 | 사이드바 아래 끝의 [설정](`gui_settings`): 테마·표시 언어·스캔 기록 자동 저장, 저장은 `app_settings`(레지스트리) | **완료** |
| 3-3. 탐색 나머지 | 사이드바 아이콘, 좁은 창에서 아이콘만 보이게 접기 | 예정 |
| 4. 다크 모드 | 시스템 테마 따르기(`WM_SETTINGCHANGE`), 색 토큰 다크 값(`theme_color`), 목록·트리·입력 칸·단추 다크 테마, 제목 표시줄 다크, 고대비면 끔 | **완료**(1차 범위: 확인 창·오른쪽 클릭 메뉴·진행 막대는 밝게 남음) |
| 5. 그래픽 | 트리맵·그래프·드라이브 막대를 Direct2D로(안티앨리어싱·둥근 모서리), 드라이브 카드 | 예정 |
| 6. DPI | Per-Monitor V2(모니터마다 다른 배율, `WM_DPICHANGED`). 지금은 시스템 DPI만 따름 | 예정 |

## 디자인 원칙

- **표준 컨트롤 우선**: 키보드 탐색·접근성(내레이터)·IME를 그대로 얻기 위해 버튼·목록·트리·입력 칸은 공용 컨트롤을 쓰고,
  모양만 다듬습니다. 직접 그리는 것은 사이드바·카드·차트처럼 표준 컨트롤이 없는 부분만입니다.
- **고정 폭 금지**: 문구가 들어가는 컨트롤의 폭은 실제 글꼴로 재서 정합니다(`theme_button_width`·`theme_check_width`).
  예전 고정 폭은 최소값으로 남겨 한국어 화면 배치는 그대로입니다.
- **시스템 설정 존중**: 글꼴 크기는 사용자의 텍스트 크기 설정(시스템 메시지 글꼴)을 따르고, 강조색·밝기 테마는 시스템 값을 씁니다.
- **실패해도 기능은 그대로**: Windows 10처럼 DWM 속성을 지원하지 않으면 조용히 기존 모양으로 둡니다.

## 디자인 토큰

색은 한곳(`gui_theme`)에 모읍니다. `theme_color(THEME_TOKEN_*)`(매크로 `THEME_COLOR_*`)가 지금 모드의 값을 돌려주고,
`theme_set_dark` → `theme_apply_window`로 모드를 바꾸면 직접 그리는 부분은 다음 그리기부터 새 색을 씁니다. 값은 Windows 11 기본 팔레트를 따릅니다.

| 토큰 | 밝게 | 어둡게 | 쓰는 곳 |
|---|---|---|---|
| `bg` | `#F3F3F3` | `#202020` | 창 배경(Mica가 비치는 자리) |
| `surface` | `#FFFFFF` | `#2B2B2B` | 카드·목록·트리·그래프 바탕, 입력 칸(어둡게), 사이드바 고른 항목 |
| `text` / `text-secondary` | `#1A1A1A` / `#5D5D5D` | `#FFFFFF` / `#C5C5C5` | 본문·보조 문구(사이드바 그룹 머리글) |
| `accent` | 시스템 강조색 | 시스템 강조색(밝은 변형) | 선택 표시(사이드바 막대·포커스), 주요 버튼, 사용률 막대 |
| `danger` | `#C42B1C` | `#FF99A4` | 경고 글자(보호 경로·설정 저장 실패), 영구 삭제 버튼 |
| `stroke` | `#E5E5E5` | `#3A3A3A` | 카드 테두리, 구분선 |
| `subtle` | `#EAEAEA` | `#272727` | 사이드바 마우스를 올린 항목 배경 |
| `face` / `frame` | 시스템 `BTNFACE` / `BTNSHADOW` | `#3A3A3A` / `#5C5C5C` | 사용률 막대 바탕·그래프 눈금·트리맵 안내 줄 / 막대·그래프 테두리 |

### 다크 모드 적용(`theme_apply_window`)

표준 컨트롤은 색만 바꿔서는 어두워지지 않으므로 컨트롤 종류마다 다르게 처리합니다. 모두 Win32 API(uxtheme·DWM)만 씁니다.

| 대상 | 어둡게 | 밝게로 되돌릴 때 |
|---|---|---|
| 제목 표시줄 | DWM `DWMWA_USE_IMMERSIVE_DARK_MODE`(20, 예전 Windows 10은 19) | 같은 속성을 끔 |
| 목록 | `DarkMode_Explorer` 테마 + 배경·글자 색. 머리글은 `DarkMode_ItemsView`, 머리글 글자색은 목록을 서브클래스해 `NM_CUSTOMDRAW`에서 지정 | 기본 테마 + 시스템 색 |
| 트리 | `DarkMode_Explorer` + 배경·글자 색 | 기본 테마 + 기본 색(-1) |
| 누름 단추·도구 설명 | `DarkMode_Explorer` | 기본 테마 |
| 체크 상자 | 비주얼 스타일을 끄고 패널의 `WM_CTLCOLORSTATIC` 색을 따름(테마를 켠 체크 상자는 글자색을 바꿀 수 없음) | 기본 테마 |
| 입력 칸·콤보 상자 | `DarkMode_CFD` + 패널의 `WM_CTLCOLOREDIT`·`WM_CTLCOLORLISTBOX`(`theme_ctlcolor`) | 기본 테마, 기본 처리 |
| 창 클래스 배경 | `theme_bg_brush`로 등록한 클래스의 배경 브러시를 지금 모드 브러시로 바꿈 | 같음 |

실제로 어둡게 할지는 `app_settings`가 정합니다: 테마 설정(시스템 따르기·밝게·어둡게), Windows 앱 모드(`AppsUseLightTheme`), 고대비(켜져 있으면 항상 밝게).
확인 창(MessageBox)·오른쪽 클릭 메뉴는 문서화되지 않은 API 없이는 바꿀 수 없어 밝게 둡니다.

간격은 4px 단위(4·8·12·16·24), 모서리는 컨트롤 4px·카드 8px입니다(모두 96 DPI 기준, `scale()`로 확대).

## 화면 구조(3단계)

위쪽 탭 대신 Windows 11 설정 앱처럼 왼쪽 사이드바를 둡니다. 아래 그림의 아이콘(▣·⚙)은 3-3단계 목표이고,
지금은 그룹 머리글과 문구만 있습니다([설정]은 문구로 아래 끝에 있음).

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ByteSieve                                               ─   □   ✕       │ ← Mica 제목 표시줄
├──────────────────┬───────────────────────────────────────────────────────┤
│ 프로젝트 분석    │  폴더 스캔                                             │ ← 페이지 제목(20pt SemiBold)
│ ▌▣ 폴더 스캔     │  ┌────────────────────────────┐ [찾아보기] [■ 스캔]   │
│  ▣ 드라이브      │  │ 스캔할 폴더 경로           │  ☐ 정밀 스캔(하드 링크) │
│ 정리             │  └────────────────────────────┘                       │
│  ▣ 프로젝트 정리 │  ┌ 카드 ───────────────┐ ┌ 카드 ────────────────────┐ │
│  ▣ 시스템 정리   │  │ 폴더 트리            │ │ 용량 순위 / 트리맵        │ │
│ 캐시             │  │                      │ │                          │ │
│  ▣ 개발 캐시     │  │                      │ │                          │ │
│ 격리·복원        │  │                      │ │                          │ │
│  ▣ 격리 폴더     │  │                      │ │                          │ │
│ 시스템           │  │                      │ │                          │ │
│  ▣ 모니터        │  │                      │ │                          │ │
│  ▣ 부스터        │  └──────────────────────┘ └──────────────────────────┘ │
│  ⚙ 설정          │  상태: 파일 1,234개 · 12.3 GiB · 오류 0               │
└──────────────────┴───────────────────────────────────────────────────────┘
```

- 메뉴는 목적별 그룹(프로젝트 분석·정리·캐시·격리·복원·시스템)으로 묶고, 그룹 머리글은 보조 글자색으로 그리며 고를 수 없습니다.
  메뉴 구성·키 이동(↑·↓·Home·End, 머리글 건너뜀, 끝에서 멈춤)·마우스 위치 판정은 창과 무관한 `nav_model`이 정해 단위 테스트하고(`test_nav_model`),
  `gui_nav`는 그리기와 입력만 맡습니다. 고른 항목이 바뀌면 부모에 `NVN_SELCHANGE`를 알립니다.
- 사이드바 항목: 문구(3-3단계에서 아이콘 Segoe Fluent Icons, 없으면 Segoe MDL2 Assets 추가), 고른 항목은 `surface` 표면(둥근 모서리)과 왼쪽 강조색 막대(▌),
  마우스를 올린 항목은 `subtle` 배경, 키보드 포커스가 있으면 고른 항목에 포커스 테두리.
- **사이드바 폭은 가장 긴 문구(머리글·항목)로 정합니다**(최소 200px). 네 언어 중 가장 긴 것은 영어 머리글 `Quarantine & restore`입니다.
  최소 창 폭은 사이드바 폭 + 폴더 스캔·설정 페이지 중 넓은 쪽의 최소 폭, 최소 창 높이는 사이드바 항목이 겹치지 않는 높이입니다.
  (3-3단계) 창이 좁으면(1000px 미만) 아이콘만 보이게 접고 마우스를 올리면 도구 설명으로 문구를 보여 줍니다.
- 아래쪽 **설정**(머리글 없는 footer 그룹, 사이드바 아래 끝에 붙음): 테마(시스템 설정 따르기·밝게·어둡게, 바로 적용),
  표시 언어(시스템 설정 따르기 + 네 언어를 그 언어 이름으로: 한국어·English·日本語·简体中文), 스캔 기록 자동 저장·기록 폴더.
  언어를 바꾸면 `HKCU\Software\ByteSieve`의 `Language`에 저장하고(시스템 따르기는 값을 지움) 바로 적용합니다:
  메인 창이 언어별 글꼴을 새로 만들어 번역된 화면(사이드바·제목·폴더 스캔·설정)에 알리고, 각 패널이 문구·글꼴·폭을 다시 정합니다
  (`scan_panel_apply_language`·`quarantine_panel_apply_language`·`settings_panel_apply_language`). GUI 스레드의 UI 언어도
  앱 언어로 맞춰(`SetThreadUILanguage`) Windows가 그리는 확인 창 단추가 같은 언어로 보이게 합니다. 상태 줄은 문구 대신 "무엇을 보였는지(종류·값)"를 기억해 두었다가
  새 언어로 다시 씁니다. 아직 번역하지 않은 페이지는 문구가 그대로라 시작할 때의 글꼴을 계속 씁니다. 페이지를 번역할 때 그 페이지의
  `*_apply_language`를 더하고 메인 창의 언어 적용에서 부릅니다.
  테마는 같은 키의 `Theme`(`system`·`light`·`dark`)에 저장합니다.
- 주요 동작 버튼(스캔·휴지통으로 이동)만 강조색으로 채우고 나머지는 보통 버튼으로 둡니다.

## 다국어

### 언어 결정

`ui_lang_detect`가 앞에서부터 처음 해석되는 값을 씁니다.

1. 환경 변수 `BYTESIEVE_LANG`(`ko`, `en`, `ja`, `zh-Hans`; `ko-KR`·`zh-CN` 같은 지역 표기 허용): 개발·테스트용
2. 레지스트리 `HKCU\Software\ByteSieve` 의 `Language`(REG_SZ): 설치 프로그램이 설치 언어로 기록하고, [설정] 페이지가 바꿈
3. Windows 표시 언어(`GetUserDefaultUILanguage`)

지원하지 않는 언어는 영어로 표시합니다. 중국어 번체(대만·홍콩·마카오)는 간체로 대신하지 않고 영어로 표시합니다.
GUI 자체 검사는 화면 문구를 한국어로 확인하므로 한국어로 고정합니다(`--self-test-lang` 제외).

### 문자열 규칙

- 모든 화면 문구는 `ui_lang.c`의 표에 네 언어를 함께 넣고 `ui_text(UI_T_...)`로 꺼냅니다. 한국어가 원문입니다.
- **문장을 조각내 이어 붙이지 않습니다.** 어순이 언어마다 달라서(한국어·일본어는 동사가 끝) "n개" + "을 옮겼습니다" 같은 조합은
  번역할 수 없습니다. 문장 하나를 서식 문자열 하나로 두고 숫자·경로는 서식 지정자로 넣습니다.
- 서식 지정자(`%ls`, `%u` 등)는 **모든 언어에서 같은 순서**여야 합니다(`test_ui_lang`이 검사). 어순 때문에 순서를 바꿔야 하는
  문장은 문장을 둘로 나누거나 표현을 바꿉니다.
- 일본어·중국어는 괄호를 전각(`（）`)으로, 영어는 Windows 11처럼 문장형 대문자(첫 글자만 대문자)로 씁니다.
- 용량 단위(KiB·MiB·GiB)와 경로·파일 이름은 번역하지 않습니다. 날짜·시각은 4단계 이후 `GetDateFormatEx`로 언어에 맞춥니다.
- CLI(`disk-scanner`) 출력과 JSON Lines 키는 다른 도구가 읽으므로 영어 그대로 둡니다.

### 글꼴

한자는 언어마다 글자 모양이 달라(한자 통합) 같은 글꼴로 네 언어를 그리면 일본어·중국어 한자가 어색하게 보입니다.
그래서 언어마다 UI 글꼴 이름을 고르고, 크기·굵기는 시스템 메시지 글꼴을 따릅니다(`theme_create_ui_font`).

| 언어 | 글꼴(앞에서부터 설치된 것) |
|---|---|
| 한국어 | Malgun Gothic |
| 영어 | Segoe UI Variable Text → Segoe UI |
| 일본어 | Yu Gothic UI → Meiryo UI |
| 중국어 간체 | Microsoft YaHei UI |

없으면 시스템 메시지 글꼴을 그대로 씁니다.

컨트롤 폭을 글자 폭으로 정하고, 최소 창 크기도 사이드바와 가장 긴 줄이 페이지 패널에 들어가게 넓힙니다.
`gui_lang_*` 테스트가 언어마다 최소 창 크기에서 사이드바 문구와 단추 문구가 잘리지 않고 패널 안에 있는지 확인합니다.
새 화면을 만들 때도 영어 기준 30~50% 길어질 수 있다고 보고 배치합니다.

## 설치 마법사

1.0.0부터 Inno Setup 6으로 만듭니다(`installer/bytesieve.iss`). 결정 사항·산출물·절차는 [release.md](release.md)에 있습니다.
설치 프로그램 제작 도구는 빌드할 때만 쓰므로 앱의 "외부 라이브러리 없음" 원칙과 충돌하지 않습니다.

- **언어 선택**: 시작할 때 언어 선택 창(한국어·English·日本語·简体中文)을 띄우고 마법사 전체를 그 언어로 보여 줍니다.
  중국어 간체 번역은 컴파일러에 없으면 저장소의 사본(`installer/languages/`)을 씁니다.
- **앱과 연동**: 고른 언어를 `HKCU\Software\ByteSieve\Language`에 `ko`·`en`·`ja`·`zh-Hans`로 기록합니다. 그래서 앱은 설치 언어로
  시작합니다. 이미 값이 있으면(앱 [설정]에서 고른 언어, 이전 설치) 덮어쓰지 않습니다. 사용자별 설치(관리자 권한 없음)라
  HKCU가 실제 사용자의 것입니다.
- **화면 구성**: 언어 선택 → 이용약관·라이선스 → 설치 위치(기본 `%LOCALAPPDATA%\Programs\ByteSieve`)
  → 구성 요소(ByteSieve 필수, `disk-scanner` 선택) → 추가 작업(바탕 화면 바로 가기, 기본 꺼짐) → 설치 → 완료([ByteSieve 실행] 체크).
  설치 프로그램 아이콘은 앱 아이콘(`res/bytesieve.ico`)과 같습니다.
- **이용약관·라이선스 화면**: 설치 언어의 조항 형식 이용약관(목적·정의·라이선스와의 관계·요금·허용/제한되는 이용·기능·
  정리 기능의 안전 장치와 이용자 책임·불법 이용의 금지와 행위자의 책임·개인정보와 데이터 처리·업데이트·지식재산권·보증 부인·
  책임 제한·종료·변경·문의)을 먼저 보여 주고, 그 아래 설치 언어의 [부록] 머리글(`[CustomMessages]`의 `LicenseAppendix`)과
  `LICENSE`(PolyForm Noncommercial 1.0.0) 원문을 **수정 없이** 붙입니다. 약관은 `installer/terms/terms-<언어>.txt`
  (`ko`·`en`·`ja`·`zh-Hans`, UTF-8 BOM)이고, 본문에서 인용하는 동의 단추 이름은 그 언어 메시지 파일의 `LicenseAccepted`와 같습니다.
  원문은 사본을 두지 않고 설치 프로그램이 실행할 때 설치하는 `LICENSE.txt`를 읽어 이어 붙이므로(`InitializeWizard`),
  `LICENSE`를 고치면 화면도 따라갑니다. 약관과 원문이 다르면 원문이 우선한다고 약관 제3조에 적습니다.
  일본어·중국어 간체 약관은 한국어·영어 약관의 번역 초안이며 검토가 필요하다고 본문 맨 위에 적습니다.
  시행일은 `@EFFECTIVE_DATE@` 자리 표시자로 두고 배포할 때 실제 날짜로 바꿉니다([release.md](release.md#릴리스-절차)).
- **설치한 뒤 약관 보기**: 약관 네 언어를 설치 폴더(포터블 ZIP 포함)의 `terms\`에 넣고, `README.txt`에서 위치를 안내합니다.
- **실행 중인 앱**: GUI가 만드는 뮤텍스 `ByteSieve.Gui.Running`으로 알아보고 닫으라고 안내합니다.
- **제거**: 설치한 프로그램 파일·바로 가기만 지웁니다. 테마·언어 설정(`HKCU\Software\ByteSieve`), 스캔 기록
  (`%LOCALAPPDATA%\ByteSieve\history`), 각 드라이브의 격리 폴더(`.bytesieve-trash`)는 **지우지 않고** 남아 있다고 알립니다
  (격리 항목은 사용자 파일이므로 자동으로 지우면 안 됨. 설정은 재설치할 때 그대로 쓰도록 남김).
- **포함 파일**: `bytesieve-gui.exe`, `disk-scanner.exe`(선택 구성 요소), `LICENSE.txt`, `README.txt`,
  `terms\terms-{ko,en,ja,zh-Hans}.txt`(이용약관). 앱 번역은 exe 안의 문자열 표라 언어별 파일이 따로 없습니다.

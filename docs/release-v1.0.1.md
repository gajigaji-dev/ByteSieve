# ByteSieve 1.0.1 개발 요약

2026-11-14에 낸 패치 릴리스(1.0.0 대비)의 개발 내용을 한 번에 볼 수 있게 정리한 문서입니다.
공식 변경 기록은 [CHANGELOG.md](../CHANGELOG.md)의 `[1.0.1]`, 배포 절차는 [release.md](release.md)에 있습니다.

## 프로젝트 배경

- Windows용 디스크 사용량 분석·정리 도구입니다. C11 + Win32 API만 쓰고 외부 라이브러리는 없습니다(MSVC `/W4 /utf-8 /std:c11`).
- core 정적 라이브러리를 CLI(`disk-scanner`)와 GUI(`bytesieve-gui`)가 함께 씁니다. core는 GUI에 의존하지 않습니다.
- 배포 파일은 설치 프로그램(Inno Setup, 관리자 권한 없이 사용자별 설치), 포터블 ZIP, `SHA256SUMS.txt`입니다. 코드 서명은 없습니다.
- 라이선스는 PolyForm Noncommercial 1.0.0이며 바뀌지 않았습니다.
- 지원 플랫폼은 Windows 10/11 x64뿐입니다. macOS·Linux는 core가 Win32 API에 묶여 있어 지원하지 않습니다([platform.md](platform.md)).
- 테스트는 단위 31개, CLI·도구 검사 32개, GUI 자체 검사 34개로 모두 97개입니다(ctest).
- 정리 원칙: 영구 삭제는 사용자가 명시적으로 확인한 경우에만 합니다. 휴지통을 쓸 수 없는 드라이브에서는 같은 볼륨의 격리 폴더(`X:\.bytesieve-trash\`)로 옮깁니다.

## 1. 다국어(핵심 변경)

- GUI의 모든 페이지를 한국어·영어·일본어·중국어 간체로 표시합니다. 문구는 번역 표 `ui_lang`에 모았습니다.
  - 대상 페이지: 폴더 스캔(상태 줄·분석 줄·트리맵·대화 상자), 격리 폴더, 프로젝트 정리, 시스템 정리, 개발 캐시, 드라이브, 모니터, Booster
- [설정]에서 언어를 바꾸면 다시 시작하지 않고 바로 적용합니다(글꼴 포함).
  - 마지막에 보인 결과(스캔·정리·복원·조회·측정)는 다시 측정하지 않고 새 언어로 다시 씁니다.
- core의 상태 문구(CLI용 한국어)는 그대로 두고, GUI에서 번역 표로 연결합니다.
- Windows 오류 설명과 확인 창의 [예]/[아니요] 단추도 앱 언어로 보입니다. 그 언어가 Windows에 없으면 기본 언어로 보입니다.
- 남은 범위: HTML 보고서와 CLI 출력은 아직 한국어만 지원합니다.

## 2. 기능 추가·개선

- **정리 완료 결과 영역**: 정리 작업(휴지통 이동, 시스템·개발 캐시 정리, 격리 폴더 복원·영구 삭제)이 끝나면 진행 막대 아래에 결과를 보여 줍니다.
  - 상태: 완료 / 일부 완료 / 완료하지 못함 / 취소됨 / 처리할 항목 없음
  - 요약: 처리한 수, 옮긴 용량, 격리 폴더로 간 수, 실패·건너뜀·취소 수
  - 다음 작업 단추: 실패 항목 보기, 격리 폴더 보기, 휴지통 열기, 다시 탐지
- **Per-Monitor DPI V2**: 배율이 다른 모니터로 창을 옮기거나 실행 중에 배율을 바꾸면 화면 전체를 새 배율로 다시 배치합니다.
  - 입력한 값, 고른 항목, 스크롤 위치는 그대로 유지합니다.
- **스캔 기록 비교 속도**: 스캔 뒤 직전 기록과 비교하는 시간이 줄었습니다.
  - `C:\Windows` 기준 비교만: 150~195 ms → 50~56 ms
  - 비교와 저장 전체: 220~340 ms → 140~170 ms
- **비교·저장을 작업 스레드로 이동**: UI 스레드를 붙잡는 시간이 줄어 창이 멈추지 않습니다.
  - 평균 313 ms → 40 ms, 최대 671 ms → 44 ms
  - 처리 중에는 바쁜 상태로 두어 다시 스캔하는 것을 막고, 창을 닫으면 저장이 끝날 때까지 기다립니다.
- **설치 프로그램 이용약관**: 설치 언어로 이용약관을 보여 줍니다(4개 언어).
  - PolyForm 원문은 수정 없이 약관 아래에 둡니다.
  - 설치 폴더와 포터블 ZIP의 `terms\`에도 넣었습니다.
  - 일본어·중국어 약관은 검토가 필요한 번역 초안입니다.
- **업그레이드**: 1.0.0 위에 덮어 설치해 업그레이드할 수 있습니다(같은 AppId). 테마·언어 설정은 유지됩니다.
- **문서**: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `docs/platform.md`를 추가했습니다. README의 설치 링크는 최신 릴리스 페이지를 가리키도록 바꿨습니다.

## 3. 버그 수정

- **작은 화면·높은 배율의 배치 문제**: 필터 줄이 페이지 밖으로 나가고, 목록이 접히고, 페이지 스크롤이 끝까지 가지 않았습니다.
  - 페이지 최소 크기 계산을 보정하고, 스크롤 막대 폭을 창의 실제 배율로 잽니다.
- **[개발 캐시]의 [모두 선택]**: 단추가 켜져 있는데 눌러도 아무것도 선택되지 않았습니다.
  - 고를 대상이 없으면 단추를 끕니다. 시스템 정리와 프로젝트 정리에도 같은 기준을 적용했습니다(선택 정책 자체는 그대로).
- **잘리는 안내 문단**: 높이가 두 줄로 고정되어 있어 긴 문구는 세 줄째부터 가려졌습니다.
  - 창 폭에 맞춰 줄을 바꾸고, 그 높이만큼 자리를 잡습니다.
- **화면 밖으로 나가는 창**: 1920×1080 화면을 200% 배율로 쓰면 최소 창 크기가 작업 영역보다 컸습니다.
  - 최소 창 크기를 작업 영역 이하로 제한하고, 자리가 모자라면 스크롤 막대를 보여 줍니다.

## 4. 릴리스 검증

- 설치 프로그램 자동 검증(`tools/test_installer.ps1`): 테스트 전용 AppId와 레지스트리 키를 써서 실제 설치본과 겹치지 않는 곳에서 확인합니다.
  - 확인 항목: 새로 설치, 1.0.0 → 1.0.1 업그레이드(언어 유지), 앱 실행 중 업그레이드 차단, 제거
- 화면을 봐야 하는 확인 목록은 [release.md](release.md#출시-전-확인-목록사람이-직접)에 있습니다(Windows 10 22H2·11 24H2, 관리자가 아닌 계정).

## 알려진 제한

- 코드 서명이 없어 SmartScreen 경고가 뜹니다.
- 다크 모드에서도 확인 창, 오른쪽 클릭 메뉴, 진행 막대는 밝게 표시됩니다.
- HTML 보고서와 CLI 출력은 한국어만 지원합니다.

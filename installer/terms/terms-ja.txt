第1条(目的)

本規約は、提供者が配布する Windows 用ディスク使用量分析・整理プログラム ByteSieve(以下「本プログラム」)の利用に関し、提供者と利用者の権利・義務および責任事項を定めます。


第2条(定義)

1. 「提供者」とは、本プログラムの著作権者である gajigaji04 をいいます。
2. 「利用者」とは、本規約とライセンスに同意し、本プログラムをインストールまたは使用する個人または団体をいいます。
3. 「本プログラム」とは、インストーラー、ポータブル版、それらに含まれる bytesieve-gui.exe(画面プログラム)と disk-scanner.exe(コマンドラインツール)、および付属の文書をいいます。
4. 「整理」とは、利用者が選択して確認したファイル・フォルダーをごみ箱または隔離フォルダーに移動すること、または利用者が別途確認した場合に完全に削除することをいいます。
5. 「隔離フォルダー」とは、ごみ箱を使用できないドライブで整理した項目を移動しておく、同じドライブ上の .bytesieve-trash フォルダーをいいます。

第7条(本プログラムの主な機能)

本プログラムは次の機能を提供します。詳細はバージョンによって異なる場合があります。

1. フォルダー・ドライブのディスク使用量分析、ツリーマップ、容量変化の追跡、結果のエクスポート(CSV・HTML)
2. プロジェクトのビルド成果物、開発キャッシュ、一時ファイル、ブラウザーキャッシュなどの整理候補の検出と整理
3. 隔離フォルダー内の項目の復元、および利用者が確認した場合の完全削除
4. ドライブ・システム状態の表示、スタートアッププログラムの有効化/無効化、利用者が選択したプロセスの終了(Booster)


第8条(整理機能の安全装置と利用者の責任)

1. 本プログラムは、利用者が自ら選択して確認した項目のみを整理します。整理した項目は Windows のごみ箱に移動し、ごみ箱を使用できないドライブでは同じドライブ上の隔離フォルダーに移動します。
2. 完全削除(ごみ箱を空にする、隔離項目の削除)は、利用者が対象を自ら選択し、別途確認した場合にのみ行われ、完全に削除したファイルは本プログラムで復元できません。
3. 本プログラムはシステムフォルダー、プログラムのインストール先など重要な場所を保護しますが、あらゆる状況でデータの損失を防ぐことを保証するものではありません。
4. 利用者は整理の前に一覧と確認画面の内容を確認する必要があり、重要なデータは事前にバックアップすることを推奨します。
5. Booster でプロセスを終了すると、そのプログラムで保存していない作業が失われる場合があります。スタートアッププログラムの設定は、いつでも元に戻すことができます。
6. 開発ツールのキャッシュを整理すると、次回のビルドやインストール時に再度ダウンロードする必要があり、オフライン環境ではビルドできない場合があります。

第10条(個人情報とデータの取り扱い)

1. 本プログラムは会員登録やログインを求めず、利用者の個人情報を収集しません。
2. 本プログラムはインターネットに接続せず、スキャン結果、ファイル一覧、使用履歴など、いかなる情報も提供者その他の場所に送信しません。すべての分析は利用者のコンピューター内でのみ行われます。
3. 本プログラムは、次の情報を利用者のコンピューターにのみ保存します。
   - 設定(テーマ、表示言語、スキャン履歴の自動保存の有無): レジストリ HKCU\Software\ByteSieve
   - スキャン履歴(フォルダーのパスと容量): %LOCALAPPDATA%\ByteSieve\history
   - 隔離した項目とその記録(元のパス、隔離日時、サイズなど): 各ドライブの .bytesieve-trash
   - 結果のエクスポートファイル: 利用者が指定した場所
4. 利用者は[設定]で、スキャン履歴の自動保存をオフにしたり、保存された履歴を削除したりできます。
5. 本プログラムをアンインストールしても、上記のデータは削除しません。特に隔離フォルダー内の項目は利用者のファイルであるため、利用者自身が確認したうえで処理する必要があります。
